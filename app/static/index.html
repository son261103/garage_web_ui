Dung lượng lưu trữ

Tình trạng node

Bắt đầu nhanh

  1. Tạo bucket ở tab Bucket (vd: media).
  2. Tạo key ở tab Khóa, lưu lại Secret key chỉ hiện 1 lần.
  3. Gán quyền đọc/ghi cho key trên bucket đó.
  4. Điền Key ID + Secret vào biến môi trường S3_ACCESS_KEY_ID / S3_SECRET_ACCESS_KEY của container admin-ui rồi chạy lại, tab File mới duyệt/tải file được.

Chưa có bucket nào

Nhấn “Tạo bucket” để tạo bucket đầu tiên, vd: media.

Mỗi key là 1 tài khoản riêng cho 1 ứng dụng. Đừng dùng chung 1 key cho mọi nơi.

Chưa có key nào

Tạo key rồi gán quyền cho bucket để ứng dụng dùng được S3.

Thư mục này trống

Nhấn “Tải lên” để đẩy file đầu tiên vào đây.

Bố cục cluster (layout)

Layout cho Garage biết node nào chứa bao nhiêu dữ liệu, ở zone nào. Chỉ xem ở đây — không đổi layout từ giao diện này để tránh làm hỏng cluster.

Node trong cluster

Tạo bucket mới

Tên bucket sẽ là tên dùng trong S3, vd media. Chỉ gồm chữ thường, số, dấu gạch ngang và dấu chấm.

Tạo key mới

Đặt tên theo ứng dụng dùng key này, vd app-key, cms-key.

Lưu lại ngay — chỉ hiện 1 lần!

Secret key sẽ không xem lại được nữa. Hãy sao chép và lưu vào nơi an toàn ngay bây giờ.
