Cài lên server

Đưa giao diện này lên roser cạnh Garage · UI chạy ở port :3910, chỉ qua Tailscale

1

Lấy code mới nhất về server

Lần đầu clone repo vào /opt/garage/admin-ui, các lần sau chỉ cần git pull.

cd /opt/garage git clone https://github.com/son261103/garage_web_ui.git admin-ui
2

File docker-compose đầy đủ đã có sẵn trong repo

docker-compose.yml trong repo gồm cả 2 service garage + admin-ui. Service admin-ui đọc Admin Token từ .env sẵn có, gọi Admin API nội bộ :3903 — không mở thêm port ra ngoài Tailscale.

cp admin-ui/docker-compose.yml docker-compose.yml # hoặc chạy script kiểm tra + build + chạy: bash admin-ui/install.sh
3

Cập nhật + chạy lại chỉ 1 lệnh

Script tự pull code mới, pull image Garage mới, build lại giao diện rồi chạy lại cả 2 container. Không xóa dữ liệu trong meta/ và data/.

cd /opt/garage bash admin-ui/update.sh
4

Mở giao diện

Từ máy đã join Tailscale, mở http://100.85.120.39:3910. Kiểm tra nhanh tình trạng:

curl http://100.85.120.39:3910/api/health

Checklist sau khi cài

  • Trang Tổng quan hiện đúng node 3ca9e56e, zone dc1.
  • Tạo bucket media rồi tạo key app-key và gán quyền đọc/ghi.
  • Mở tab File & ảnh — giao diện tự dùng key vừa tạo, không cần điền gì thêm vào .env.
  • Port 3910 chỉ nghe qua Tailscale, không public ra internet.
